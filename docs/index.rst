glpi-python-client Documentation
================================

``glpi-python-client`` is a typed Python package for interacting with GLPI ITSM APIs.
It provides a reusable ``GlpiClient`` object, typed models, OAuth2 token
handling, and helpers for ticket, user, location, and document workflows.
